# 分析報表設計 — REPORT_DESIGN.md

> 四張給老闆看的分析表：客戶、業務、銷售、公司。互動樣稿（用 2024/01–2026/09 真實資料）另見 Claude 產出的「聲活・東吳・鉑霖 分析報表設計」頁面；本文件是可進版控的文字版：設計理由、每張表的結構、指標定義。

## 1. 設計原則

| 原則 | 意思 | 為什麼 |
|---|---|---|
| 一頁回答一個問題 | 每張表由上而下：KPI（結論）→ 圖（結構）→ 排名表（誰）→ 警示清單（該做什麼） | 老闆看前 10 秒要有答案；想追再往下捲 |
| 同期比較是標準欄位 | 今年 YTD 對去年同一段月份；每張表的「同期」欄都是這個口徑 | 員工現在每月手做「客戶同期比較表」，內建就不用做 |
| 三層毛利、一套定義 | 帳上 / 集團 / 淨利三個數字全系統同算法，表頭寫清楚是哪一層 | 舊系統 134 張報表裡的「毛利」互相對不起來，是老闆最常抱怨的事 |
| 排除干擾，但看得到 | 內部轉撥、交換、公司戶預設不進排名，另欄顯示金額 | 不消失（財務要對帳）、不灌水（排名才有意義） |
| 排名附佔比與累計 | 「第 1 名 2,485 萬」沒意義，「第 1 名佔 24%、前 10 名佔 53%」才是集中度 | 客戶依賴度是策略問題 |
| 顏色跟著實體走 | 聲活藍、東吳綠、鉑霖橘沿用老闆儀表板；平台歸類同色系深淺；紅黃只用在警示 | 四張表色彩語言一致，老闆不用重新學 |

## 2. 共同定義

### 2.1 三層毛利
| 層 | 算法 | 誰看 | 對應現況 |
|---|---|---|---|
| 帳上毛利 `booked_profit` | 除佣實收 − 實付 | 各公司自己 | 舊系統「帳上毛利」；子公司的實付含付給聲活的 65 折 |
| 集團毛利 `group_profit` | 對外收入 − 對外成本（把子公司付給聲活的轉撥加回） | 老闆 | 「喬商年度發稿明細」裡「聲活」那組欄位的集團版；需求 PDF 的「第二層」 |
| 集團淨利 `net_profit` | 集團毛利 − 平台固定成本（企頻 75 萬/月、新鮮視 100 萬/月，依 `fixed_cost_rule`） | 老闆 | 訂單與客戶層按當月該平台歸類的對外除佣實收比例分攤，所以每張訂單都有「集團淨利率」 |

驗證：合約 1130825-6-6（2025/01）東吳對客戶線 除佣 380,952 / 實付 247,619；聲活-東轉撥線 247,618。帳上毛利 = 133,333（35%）；集團毛利 = 380,952（100%，企頻無逐單成本）；集團淨利 = 380,952 − 分攤固定成本。

### 2.2 預設排除
- **內部轉撥線**：組別 聲活-東 / 聲活-鉑（`is_intercompany`）。不算客戶、不算業務、不算訂單；只在集團層還原成本。
- **交換（barter）**：業務名稱結尾「換」（陳絜心換、江曼瑄-換）或廣告名稱含「交換」（`is_barter`）。金額 = 成本，沒有現金毛利；另欄顯示，與老闆儀表板的「交換總計」一致。
- **公司戶**：業務 = Company（`is_house`）。在客戶 / 銷售 / 公司分析含入；在業務排名另列不排名。

### 2.3 狀態
新客 = 今年第一次有業績；既有 = 去年也有；回流 = 更早有、去年沒有、今年又有；流失風險 = 去年有、今年到目前沒有（年度結束後轉「流失」）。資料自 2024/01 起，2024 全部是「起始年」，狀態判斷從 2025 起可靠。

### 2.4 期間
分析頁的期間是「業績年月」區間，預設今年 1 月到 `v_as_of`（有資料且不晚於本月的最大月）。同期 = 去年相同月份區間。年度 view（`v_customer_year` 等）含未來月份的預登，只用於狀態 / ABC / 年度總表。

## 3. 四張表

### A. 客戶分析 — 「誰在養公司、依賴多高、哪個產業在長、誰快掉了」
1. KPI：活躍客戶數（同期）、新客、流失風險、客戶平均貢獻（同期）、前 10 大佔比（同期）、帳上毛利率（副：集團毛利率）。
2. ABC 分級橫條（累計 80% / 95% / 其餘）＋ 產業別橫條（金額、家數、毛利率、前 8 + 其他）。
3. 客戶價值矩陣：x 除佣實收（平方根刻度）、y 帳上毛利率、大小 訂單數、形狀+顏色 狀態；16% / 35% 兩條參考線；四象限對應策略提示（核心維護 / 檢討報價 / 可擴大 / 評估續做）。
4. 排名表：狀態、除佣實收、同期 %、佔比 + 累計、帳上毛利、毛利率、集團淨利率、頻率（筆數 + 活躍月數）、平均單筆、平台組合、月趨勢、策略提示。
5. 流失風險清單：去年同段 ≥ 30 萬（可調）、今年無業績，附距上次交易月數。
6. 下鑽：客戶頁（24 個月趨勢、歷年同期比較、訂單清單三個毛利率、平台組合變化、經手業務）。

### B. 業務分析 — 「量與質並列」
1. KPI：有業績的業務人數（公司戶另計）、人均除佣實收、人均客戶數 / 新客、業務業績合計、交換另計。
2. 排名表：除佣實收（相對長條，顏色依公司）、同期 %、佔比、帳上毛利、毛利率、集團淨利率、認定業績、客戶數 + 新客、訂單數 + 平均單筆、前 3 大客戶依賴度（≥70% 紅 / ≥50% 黃）、平台組合、交換。
3. 業務 × 月熱圖（取代 業務 × 平台 × 月 的大表）。
4. 下鑽：業務頁（月趨勢、客戶組合與同期、新客 / 流失、目標達成與每月需達、預估 pipeline、連到認定表與獎金）。

### C. 銷售分析 — 「分佈比平均重要」
1. KPI：有收入訂單數、平均單筆 + 中位數、大單 ≥100 萬、低毛利 <16%、零收入成本單（製作費 / 營運）、帳上毛利率（含成本單 / 只看有收入）。
2. 訂單金額分佈（級距）＋ 毛利率分佈（<0 / 0–16 / 16–35 / 35–50 / >50）。
3. 產業 × 平台歸類熱圖。
4. 訂單排名（可依金額 / 毛利 / 毛利率 / 淨利率排序），三個毛利率並列。
5. 低毛利清單：可直接填「低毛利原因」（取代舊系統的低毛利原因登錄表單）。

### D. 公司分析 — 「三家公司加起來到底賺多少」
1. KPI 四卡：三家公司（除佣實收、同期、帳上毛利、轉撥）＋ 集團合併（集團毛利、淨利）。
2. 各公司月業績堆疊柱 ＋ 三層毛利橋（帳上 → ＋轉撥 → 集團毛利 → －固定成本 → 淨利）。
3. 目標達成表（`sales_target` × 實績；口徑同老闆儀表板：企頻＋新鮮視、不含公司戶、不含交換）：目標 / 進單 / 待追 / 達成率 / 剩餘月份每月需達 / 加預估後達成率。
4. 公司 × 平台歸類表（金額、組合、毛利率、業務人數、人均產值）。
5. 進單＋預估（`forecast`）公司 × 月，對應老闆的大總表。

## 4. 現有報表對應

| 現在 | 新系統 |
|---|---|
| 公司業績儀表板（Q3 目標 / 達成率 / 月堆疊） | 公司分析：KPI + 月堆疊 + 目標達成表 |
| 進單＋預估大總表 / 進單總表分業務 | 公司分析（進單＋預估）／業務分析熱圖 |

| 喬商・彥星年度發稿明細（三組毛利欄） | 客戶頁訂單清單：帳上 / 集團 / 淨利三欄 |
| 舊：綜合成本毛利分析 | 公司分析矩陣；銷售分析明細 |

## 5. 待確認（列入 ASSUMPTIONS）
1. 三層毛利定義是否如 §2.1；瑞迪是否仍營運（2025 起無業績）。
2. 固定成本歸屬聲活、2025 的固定成本數字（有了才能做淨利同期）。
3. 目標口徑（企頻＋新鮮視、不含公司戶）與 Q3 目標值；聲活 7 月 139 萬 vs 儀表板 147 萬的差異。
4. 交換的判斷規則是否完整（目前：業務名結尾「換」或廣告名含「交換」）。
5. 客戶異名合併（同一客戶不同寫法）由誰維護。
