# 同仁使用手冊 — USER_GUIDE.md

新業績系統（聲活 / 東吳 / 鉑霖）。全繁體中文，手機/平板也可用。

## 登入

- 用管理者給你的帳號與**初始密碼**登入；系統會要求你**立即修改密碼**才能使用其他功能。
- 忘記密碼找管理者（EXEC）在「使用者管理」重設。
- 系統閒置一段時間後第一次開啟可能要等 30–60 秒喚醒，屬正常。

## 角色與看得到的頁面

| 角色 | 可用 |
|---|---|
| 媒體人員 MEDIA | 首頁、業績登打/查詢、客戶、平台/電台/節目維護、發票（唯讀）、報表 |
| 財務 FINANCE | 首頁、業績查詢（唯讀）、客戶（唯讀）、發票與銷帳、報表 |
| 高階 EXEC | 全部（含主檔維護、問題回報清單、稽核、使用者管理） |
| 業務 SALES | 首頁、業績查詢、報表、獎金（**都只看自己**） |

每頁左側都有 **💬 回報問題**，用得不順、發現錯誤、想要新功能都可以直接回報。

## 各頁功能

- **🏠 首頁**：本月各公司 KPI（實收/除佣/毛利/毛利率）、近 12 個月趨勢圖、本月平台歸類佔比、最近回報的問題。
- **✍️ 業績登打**：輸入合約編號按「載入/新建」；上面填合約基本資料（公司、客戶、業務、業績類別…），下面用表格一列一條業績線（平台、金額、檔次…）。除佣實收留空會自動算。子公司（東吳/鉑霖）線可按「產生子公司轉撥線」一鍵帶出 65 折轉撥線。填好按「儲存」。
- **🔍 業績查詢**：用年月、公司、業務、客戶等條件查；可勾「低毛利」快速篩選；可下載 Excel；媒體/高階可點合約跳到登打頁修改。
- **🏢 客戶主檔**：查、改客戶資料與別名；可把重複客戶「合併」（需二次確認）。
- **🗂️ 主檔維護**：平台/電台/節目/業務/組別/產業別/業績類別/各種規則（固定成本、轉撥、獎金）用表格直接編輯後儲存。最下方另有「🎯 目標 / 🔮 預估」兩個 tab，維護業績目標與預估（分析頁的目標達成、進單＋預估就從這裡來）。

### 分析頁群（常用 / 客戶 / 業務 / 銷售 / 公司）

- **⭐ 常用分析**：老闆工作簿「三公司發稿明細分析」的完整重現——說明與假設、平台總計總覽、客戶數統計與客戶排名、聲活／東吳／鉑霖 年度發稿明細、原始資料，共 7 張表，畫面／Excel／PDF 一模一樣（同區塊、欄位、順序、顏色、數字格式）。期間可選：**去年整年**（＝工作簿口徑，預設）、今年至今、自訂起迄月；2026 起自媒體多一欄「健康視」。右上三顆鈕：下載整本 Excel／PDF／列印版 HTML，每張表也能單獨印。口徑＝發稿口徑（媒體上稿線、交換併回原業務、瑞迪併入東吳、客戶數含 0 元客戶）。
- **👥 客戶分析**：誰在養公司、依賴多高、哪個產業在長、誰快掉了。6 個 KPI 都附同期；ABC 分級與產業別長條、客戶價值矩陣；客戶排名表（點一列 → 客戶頁、可下載完整名單）與流失風險清單。
  *老闆會問：* 「80% 業績靠幾家？」→ ABC + 前 10 大佔比；「哪個產業值得投資？」→ 產業別長條；「誰快掉了？」→ 流失風險清單。
- **🧑‍💼 業務分析**：量（金額、佔比、同期）與質（毛利率、新客、依賴度）並排。排名表點一列 → 業務頁；業務 × 月熱圖；公司戶另列不排名。
  *老闆會問：* 「誰做得好？」→ 金額＋毛利率；「誰有風險？」→ 前 3 大依賴度（≥70% 紅）；「誰在開發？」→ 新客數。
- **🧾 銷售分析**：訂單層的定價與成本。金額分佈、毛利率分佈、產業 × 平台歸類熱圖；訂單排名（可切換排序、點一列 → 登打修改）；低毛利清單可直接填「低毛利原因」。
  *老闆會問：* 「大單還是小單重要？」→ 金額分佈；「低毛利是個案還是常態？」→ 毛利率分佈；「這張單賺不賺？」→ 三個毛利率並列。
- **🏛️ 公司分析**：三家公司加起來到底賺多少。四張 KPI 卡（三家 + 集團）；月堆疊柱＋三層毛利橋（帳上 → ＋轉撥 → 集團毛利 → －固定成本 → 淨利）；目標達成（含每月需達）；公司 × 平台歸類與人均產值；進單＋預估。
  *老闆會問：* 「集團到底賺多少？」→ 三層毛利橋；「目標追得到嗎？」→ 每月需達；「哪家在成長？」→ KPI 卡同期。
- **🔎 客戶頁 / 🧑 業務頁**：從分析頁點列進來（也可自己選）。客戶頁：24 個月趨勢、歷年同期、訂單三層毛利率、平台/業務變化；業務頁：月趨勢、客戶組合、新客/流失、目標達成、預估 pipeline。
- **💳 發票與銷帳**（財務）：看應收/逾期；新增發票；登錄銷帳（一張發票可多次）；舊資料可批次「標記已結清」。
- **📈 報表中心**：選報表 → 設篩選 → 查詢 → 看表格與合計 → 下載 Excel 或列印版（列印版按瀏覽器列印可存 PDF）。含成本毛利、雙層毛利、媒體發稿量、業績認定、業績成本（自訂區間）、應收帳款、業務獎金、客戶排名，以及分析整年表：客戶年度、業務年度、產業年度、集團三層毛利月表、目標達成、進單＋預估。
- **🎯 業務獎金**：選年月看第一層業務獎金（業務 × 平台歸類 × 業績項目）。目前只做第一層，其他獎金尚未實作。
- **📮 問題回報清單**（高階）：看所有人回報的問題，改狀態與回覆。
- **🕵️ 稽核紀錄**（高階）：查誰在什麼時候改了什麼（欄位舊值 → 新值）。
- **👥 使用者管理**（高階）：新增/停用帳號、重設密碼、改角色、綁定業務。
- **🔑 修改密碼**：改自己的密碼。

## 怎麼印（給老闆的 PDF、給同仁的 Excel）

每一個「看數字」的頁面，最下面都有一排匯出鈕（首頁與四個分析頁的篩選列旁也有捷徑）：

- **📄 產生 PDF**：按下後伺服器排版（約 3–8 秒），完成出現「⬇ 下載 PDF」。這份就是**畫面上看到什麼、印出來就是什麼**——封面有期間／口徑／篩選、表頭每頁重複、頁尾有頁碼，適合直接給老闆印。
- **📊 下載 Excel**：立即下載。第一張是「摘要」（KPI＋目錄），後面每張表一個工作表，數字是真的數字（可再加總、可畫圖），列印設定都設好了（A4、一頁寬、每頁重複表頭）。
- **🖨 列印版 HTML**：任何環境都能按；開啟後按瀏覽器列印（Ctrl+P）就能存成 PDF。列印對話框請**取消「頁首及頁尾」、勾選「背景圖形」**。
- **老闆一頁 / 📦 月報包**（高階，在首頁）：一鍵把首頁摘要＋公司／客戶／業務／銷售分析整包成**一個 PDF**（頁碼連續）＋每頁一個 Excel，壓成 zip 下載。

看不懂的欄位／數字，滑鼠移到表頭（畫面）或看表格下方的小字說明——例如「同期＝去年的同一段月份」「佔比＝該列 ÷ 期間合計」「三層毛利率：帳上→集團→淨利」。三處（畫面／PDF／Excel）說明一致。

## 小提醒

- 金額顯示千分位、無小數；比率一位小數；年月顯示 2026/09。
- 報表的合計列毛利率是「總毛利 ÷ 總除佣」重算，不是把每列毛利率平均。
- 有任何對不上的數字，先用「💬 回報問題」記下來，管理者會處理。
