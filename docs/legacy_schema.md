# 舊系統（Access）結構盤點 — legacy_schema.md

來源檔：`聲活.東吳.鉑霖2026起業績統計系統V109g -.mdb`（Access 2000 格式，22 MB）。以 mdbtools 匯出。

- 使用者資料表 61 張、已儲存查詢 199 個（另有 307 個表單內嵌的 ~sq_ 查詢）、表單 65 個、報表 134 張、VBA 模組 1 個（PWD）。
- 連結表 1 張：`CUE號資料表` → `\\Rmms\共用資料\結案流程控管系統\結案作業流程控管.mdb`（另一套 Access 系統，本次不在範圍）。
- 所有 join 皆以文字欄位（客戶名稱、業務、電台…）比對，沒有主鍵/外鍵。
